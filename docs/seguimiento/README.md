# Seguimiento

Un archivo por hito de seguimiento: `AAAA-MM-DD_<hito>.md`, con:

- Tareas cerradas (con sus incidencias y PR) y las que quedan
- Indicadores de `docs/01_requisitos.md` alcanzados, con su cifra
- Riesgos materializados y cómo se resolvieron
- Horas y personas implicadas; materiales generados
- Resumen de `/ponytail-audit` (calidad del repositorio) y `/ponytail-debt` (atajos `shortcut:`
  pendientes), que Claude ejecuta por iniciativa propia al cerrar cada fase
