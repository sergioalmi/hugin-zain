# tools/

Herramientas de desarrollo, una carpeta por herramienta (`tools/<nombre>/main.py` o equivalente):
medición de rendimiento, simuladores y dobles de piezas (un cliente o servidor «de mentira» para
probar una pieza sin las demás), comprobaciones de calidad. Cada herramienta estable se apunta en
la sección «Comandos» de `CLAUDE.md` y, si la usa una persona, en `docs/09_como_arrancar.md`.
